# Математика разными способами

Математика 1–11 классов на русском и казахском. 1 класс — сложение и вычитание до 20, каждый пример несколькими способами. 2–11 классы — темы по четвертям программы РК (121 тема, 3 уровня), практика в формате ЕНТ для 10–11 классов.

**Открыть:** https://niphridium.github.io/math/

- Разбор примера — 4 способа решения с подсказками по шагам.
- Тренировка — 10 примеров на одну тему, после каждого ещё один способ решения.
- Задача дня — 3 задачи в день: лёгкая, средняя и потруднее.
- «Конфетная фабрика» и «Погнали!» — занятие дня короткой лентой клипов: посчитай конфеты, больше или меньше, собери пример, мини-босс, сундук со стикером (виден заранее) и «На сегодня всё». Следующий клип — только по свайпу ребёнка, без таймеров и серий дней.
- Урок «Складываем до 10»: посмотри → решим вместе → реши сам → повтори позже.
- «Тренды» — тематические наборы заданий по программе 1 класса (блоки, питомец, Луна, котёнок-рыцарь, ферма) со сроком показа.
- Свой мир у каждой группы классов: «Конфетная фабрика» (1), «Квест-мир» (2–4), «Лаборатория» (5–6), «лента·матем» (7–9), «ЕНТ Pro» (10–11); занятие дня — 10 клипов с повторением тем по дням, мини-босс, сундук со стикером, «Тренды» по возрасту.
- Для родителей — статистика и настройки.

**Матквест** (игра-квест, 2–4 класс, без привязки к программе): https://niphridium.github.io/math/quest/ — у каждого класса свой мир: «Динопарк» (2), «Остров-обби» (3), «Квест-мир» (4); 5 миров × 4 уровня + страж, блиц, награды. Ссылка `quest/#/grade/3` сразу открывает нужный класс. Один файл `quest/index.html`, прогресс — только в браузере.

Профили и прогресс хранятся только в браузере на этом устройстве и никуда не отправляются. Сохраняются только имя или прозвище ребёнка и картинка-зверёк.

В репозитории лежит готовая сборка веб-приложения (статические файлы для GitHub Pages).
